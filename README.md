# Encapsulamento — Treino

Atividade de treino em Dart para praticar encapsulamento: atributos privados, getters e setters com validação, classes abstratas e leitura de dados a partir de JSON.

O código fica na pasta `atvd`. Execute com `dart run` a partir dela para testar o programa e conferir as respostas das questões no `atvd/README.md`.
